# Engineering & Design Decisions — PulseAgent

### 1. Ingestion & Visual Strategy vs. Rejected Alternatives
We chose an interactive, DOM-rendered trace inspector driven by hand-rolled CSS transitions and native `IntersectionObserver` over video captures or runtime animation frameworks like Framer Motion. Video assets are static, non-inspectable, and bloat initial page load by several megabytes, whereas an in-DOM mock dashboard allows developers to click through nodes, inspect real JSON payloads, and simulate deterministic replays live in the browser. Using pure CSS transitions and keyframes for all core UI motion aligns directly with our sub-millisecond telemetry ethos by eliminating runtime animation bundle overhead (with `canvas-confetti` imported solely for the self-contained Konami-code easter egg). In exchange, we gave up complex spring-physics gestures and drag-and-drop graph canvas rearranging in favor of a clean, restrained, horizontal timeline sequence with subtle cubic-bezier easing.

### 2. Time-Constrained Trade-offs & A "Full Week" Scope
Under tonight's time limit, we prioritized depth and authenticity in the core telemetry inspector—wiring realistic multi-agent failure states (Stripe API 429 timeouts, Cloudflare WAF bot blocks, LangGraph conditional fallback routing, latency waterfalls, and model-specific token costs) alongside complete dark/light theme persistence and responsive layouts. If given a full week, we would expand the linear timeline into a 2D topological DAG canvas (using Canvas/SVG) supporting parallel branches and cyclic loops, implement a comprehensive WCAG AAA keyboard navigation pass with ARIA live regions for step transitions, and connect the sandbox to a live WebSocket emulator that streams synthetic telemetry with adjustable error injection rates.

### 3. AI Usage & Personal Verification Log
AI tools were used to accelerate the initial boilerplate scaffolding of data schemas (`AgentScenario`, `TraceStep`, `TokenMetrics`), initial mock JSON structures, and Tailwind layout utility composition for secondary sections. Following generation, every line was personally audited and refined: maintaining clean, type-stripped modular React JavaScript with zero runtime errors, recalibrating the failure pulse animation (`@keyframes failure-pulse`) to maintain subtle visual restraint, removing all synthetic logos or fabricated testimonials to ensure honest product positioning, and verifying that the layout renders with zero horizontal scroll overflow at both 390px and 1440px viewports.
